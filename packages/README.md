# Packages

This folder contains reusable artifacts for use by systems.

## Folder Structure

| Folder | Description |
| --     | -- |
| apps   | Reusable web applications |
| components | Reusable UI parts that do not represent a full page. Can be as little as a button, or can be an insert dialog, etc. They are generally reusable and have no dependency on blocks/tables
| enums | Reusable enums. |
| blocks | Reusable system blocks. See [blocks](../docs/concepts/blocks.md) for more information.|
| field_groups | Reusable table fields. |
| pages | Reusable UI pages.|
| services | Wrapper code for calling web services and defining and using web hooks.|
| std | Core reusable elements, such as the YOM, system and more. |
| table | Reusable database table. |
| table_blocks | Reusable table blocks. See [blocks](../docs/concepts/blocks.md) for more information.|
| tables | Reusable set of database tables. |
